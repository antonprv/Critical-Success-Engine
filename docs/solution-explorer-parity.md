# Solution Explorer: паритет с Visual Studio (S6-20)

Эталон — Solution Explorer Visual Studio 2022 (по общим знаниям; **[проверить по актуальной версии]**). Колонка «У нас»
показывает, где это сделано: модель `@cse/solution` (`Modules/Editor/Solution`), дерево `WinSolutionTree` и
`SolutionTreeController` в `@cse/ui`, файлы проекта в главном процессе (`Programs/Desktop`, `SolutionService`).
Подключение к инструментам (UIDesigner, редактор таблиц, менеджер проектов) — задачи S6-19, S6-17, S6-18.

## Что сделано не так, как в задаче, и почему

- **Манифест хранит не все файлы.** `task.md` исходит из того, что манифест хранит относительные пути всех файлов. На
  деле `Ui.manifest.json` перечисляет только UI-документы. Поэтому источник правды о составе — **диск**, манифесты
  инструментов дополняют его (файл, который манифест знает, а на диске его нет, показывается как пропавший). Источник
  правды о представлении — `.uisolution`.
- **Режим «виртуальные папки» по умолчанию скрывает служебные файлы** (`*.uisolution`, `*.cseproject`, `*.csproj`,
  `*.esproj`, `*.slnx`, `*.sln`), как и Visual Studio. В остальном при свежем `.uisolution` оба режима показывают
  одно и то же: папка проекта под одним проектом (проверено тестом `Tree.test.ts`).

## Формат `.uisolution`

Лежит рядом с `.cseproject`, обычный JSON с отступами, ключи в постоянном порядке (два сохранения дают одинаковые
байты). Поля: `Mode`, `Projects` (`Id`, `Name`, `Folder` — привязанная папка или `null`, `Parent`), `VirtualFolders`
(`Id`, `Name`, `Parent`), `Placements` (путь → место в режиме решения), `Hidden`, `HiddenPatterns`, `ShowHidden`,
`Expanded` (по режимам). Места: `s` — решение, `p:<id>` — проект, `v:<id>` — виртуальная папка, `d:<путь>` —
реальная папка. Подробно — `Modules/Editor/Solution/Source/SolutionFile.ts`.
