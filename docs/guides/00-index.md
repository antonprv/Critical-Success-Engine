## Модель в одном абзаце

Игра - это **сцены**. Сцена - это **данные**: список сущностей, у каждой сущности список компонентов
(`Ent("Имя", [Comp(Компонент, { поле: значение }), …])`). Поведение пишется в **компонентах** - обычных TypeScript-классах
с хуками (`Awake`, `Start`, `Update`, `OnPhysicsUpdate`, `OnCollisionEnter`, …). Всё остальное (рендер, физика, меню) -
сервисы, до которых компонент достаёт через `this.Engine`.
