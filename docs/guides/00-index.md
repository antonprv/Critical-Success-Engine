## Модель в одном абзаце

Игра — это **сцены**. Сцена — это **данные**: список сущностей, у каждой сущности список компонентов
(`Ent("Имя", [Comp(Компонент, { поле: значение }), …])`). Поведение пишется в **компонентах** — обычных TypeScript-классах
с хуками (`Awake`, `Start`, `Update`, `OnPhysicsUpdate`, `OnCollisionEnter`, …). Всё остальное (рендер, физика, меню) —
сервисы, до которых компонент достаёт через `this.Engine`.

## О чём честно предупреждаю

- Физика (BEPU в wasm) собирается отдельно (`dotnet`), и **в браузере я её не запускала**: C#-мост проверен компиляцией
  против настоящих исходников, TypeScript-сторона — тестами с поддельным мостом. Первый запуск «с живой физикой»
  стоит пройти руками: сцена *Character test room* (см. 01).
- Всё, что ниже называется «проверено», проверено в тестах/сборке, но не глазами в браузере.
