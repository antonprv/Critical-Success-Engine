# CSTables: формат `.cstables` (S6-01)

Таблицы переводов по ключам, как `.resx` в Visual Studio. Пакет — `@cse/cstables` (`Modules/Common/CSTables`): формат,
проверки, генератор кода, рантайм. Сборка в Node (файлы, плагин Vite) — `@cse/cstables/build`.

## Файлы и языки

- Таблицы лежат в `Resources/` проекта (в любых подпапках).
- `UiNames.cstables` — базовый язык таблицы `UiNames` (по умолчанию русский, `BaseLanguage` сборки).
- `UiNames.en.cstables`, `UiNames.pl.cstables`, `UiNames.pt-BR.cstables` — переводы. Язык берётся из имени файла,
  поэтому новый файл добавляет язык без правки кода.
- Кодировка UTF-8, с BOM или без; переводы строк любые (файл сохраняется с теми, что в нём были).

## Строки файла

```
@access public
# Комментарий прямо над ключом — комментарий ключа (колонка Comment в редакторе).
MenuTitle = Главное меню
Greeting = Привет, {name}!
Pair = {0} и {1}
Padded = "  пробелы по краям сохраняются  "
Braces = Фигурные скобки как текст: \{ и \}
Coins[one] = {count} монета
Coins[few] = {count} монеты
Coins[many] = {count} монет
Coins[other] = {count} монеты
About = """
Несколько строк,
  отступы сохраняются.
"""
```

| Строка | Смысл |
|---|---|
| `Key = value` | ключ и значение; пробелы вокруг `=` и по краям значения не входят в значение |
| `Key = "value"` | значение в кавычках: пробелы по краям сохраняются, `\"` — кавычка |
| `Key = """` … `"""` | многострочное значение; строка из одних `"""` внутри пишется как `\"""` |
| `Key[form] = value` | форма множественного числа: `zero`, `one`, `two`, `few`, `many`, `other` (правила CLDR языка, `Intl.PluralRules`); `other` обязательна |
| `# текст` | комментарий; комментарии прямо над ключом — комментарий ключа |
| `@access public` / `internal` / `none` | уровень доступа таблицы (как Access Modifier в редакторе ресурсов VS): `none` — без генерации кода |
| пустая строка | сохраняется как есть |

- **Ключ:** буква или `_`, затем буквы, цифры, `_`.
- **Экранирование в значении:** `\n`, `\t`, `\\`, `\"`, `\{`, `\}`; остальное после `\` остаётся как написано.
- **Аргументы:** `{0}`, `{1}` (по позиции) или `{name}` (по имени). У множественных ключей аргумент `{count}` — само
  число.

Документ хранит каждую строку как была: при сохранении из редактора меняется только то, что правили (комментарии,
пустые строки и форматирование остаются).

## Проверки

| Код | Уровень | Что |
|---|---|---|
| CST001, CST002, CST003, CST004 | ошибка | строка не читается: нет `=`, плохой ключ, неизвестная форма числа, нет закрывающих `"""` |
| CST010 | ошибка | ключ (или его форма) повторяется |
| CST011 | предупреждение | скобка, которая не открывает аргумент (пишите `\{`) |
| CST012 | предупреждение | пустое значение |
| CST013 | ошибка | у множественного ключа нет формы `other` |
| CST014 | ошибка | ключ и обычный, и множественный |
| CST020 | предупреждение | ключ базового языка не переведён |
| CST021 | предупреждение | ключа нет в базовом языке: перевод не используется |
| CST022 | предупреждение | аргументы перевода не совпадают с базовым языком |
| CST023 | предупреждение | ключ множественный в одном языке и обычный в другом |
| CST030, CST034 | ошибка | плохое имя таблицы или кода языка |
| CST031 | ошибка | одна и та же таблица (и язык) лежит дважды |
| CST032 | ошибка | перевод без базовой таблицы |
| CST033, CST035 | предупреждение | ключ есть в нескольких таблицах или совпадает с именем таблицы: короткого доступа у него нет |

Ошибки останавливают сборку; с `WarningsAsErrors` — и предупреждения.

## Сгенерированный код

Сборка пишет в `Source/Generated/`: `CSTables.ts` и по модулю на язык (`CSTables.ru.ts`, `CSTables.en.ts`...).

```ts
import { CSTables, CSTablesRuntime } from "./Generated/CSTables";

CSTables.UiNames.MenuTitle;            // перевод для текущего языка в момент обращения (геттер)
CSTables.MenuTitle;                    // то же, если ключ есть только в одной таблице и не совпадает с именем таблицы
CSTables.UiNames.Greeting({ name });   // ключ с именованными аргументами
CSTables.UiNames.Pair(a, b);           // ключ с позиционными аргументами
CSTables.UiNames.Coins(3);             // множественный ключ: сначала число
await CSTablesRuntime.SetLanguage("en");
CSTablesRuntime.OnLanguageChanged((language) => { /* обновить тексты */ });
```

- **Коллизии имён:** у каждого ключа есть доступ через таблицу (`CSTables.Таблица.Ключ`); короткий доступ
  (`CSTables.Ключ`) — только если ключ уникален во всех таблицах и не совпадает с именем таблицы.
- **Доступ:** `internal` помечает члены `@internal`; `none` — кода нет, ключи доступны по имени
  (`CSTablesRuntime.Id("Таблица.Ключ")`).
- **Ленивые языки:** базовый язык входит в сборку сразу, остальные загружаются при первом выборе.

## Рантайм

`Localization`: поиск ключа — чтение массива по целому id, без аллокаций и хешей. Цепочка запасных вариантов:
текущий язык → базовый язык → имя ключа (с предупреждением в логе, один раз на ключ). Язык при старте —
`PickLanguage(navigator.languages)`: запомненный, иначе первый подходящий системный (`pt-BR`, затем `pt`), иначе
базовый. `Remember(memory)` сохраняет выбор (например в `SettingsStorage`).
